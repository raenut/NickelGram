# NickelGram 0.1.0

## 首次发布

- 通过 NickelMenu 将选中文字发送到 Telegram。
- 发送当前书籍最近一条高亮或批注。
- 将全书高亮和批注导出为 Markdown，并发送到 Telegram。

# NickelGram 0.1.0

## Initial release

- Send selected text to Telegram through NickelMenu.
- Send the latest highlight or annotation from the current book.
- Export a book's highlights and annotations as Markdown and send the file
  to Telegram.
