# NickelGram 0.1.1

## 改进

- 全书导出按阅读顺序和章节整理高亮、批注。
- 导出菜单更名为 **Export All Highlights**。
- Markdown 文件保存到 Kobo 根目录的 `Highlights/`，并发送到 Telegram。

- 部分书籍可能显示 HTML 文件名，而不是章节标题。
